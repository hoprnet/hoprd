Module state_dump

Expand description

Periodic component state reporting, run by the node alongside its other tasks.

The chain connector, channel graph and P2P transport each own their snapshot schema, timer, record budget and assessment. Every interval each emits one INFO record with event = "component_state", tagged with the component name and this node’s instance.

HOPR_STATE_DUMP_INTERVAL sets the interval in seconds: 60 by default, 0 disables reporting, and other values must lie within 5–86400. An invalid value stops reporting with an error but leaves the node running.

With JSON logging, extract the records with:

jq 'select(.fields.event == "component_state") | .fields.state | fromjson' node.jsonl
