pub(crate) async fn save_outgoing_ticket_indices(

    shutdown: Receiver<()>,
)
Expand description

Saves the outgoing ticket indices every OUTGOING_TICKET_INDEX_SAVE_INTERVAL.

Saves go through this one task, so they cannot interleave: save_outgoing_indices snapshots each index before taking the store write lock, and two concurrent saves could write an older value last. On shutdown the task returns without saving – the caller saves the final indices, once nothing else can issue new ones. Returning also drops this task’s clone of the factory.
