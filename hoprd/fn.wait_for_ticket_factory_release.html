pub(crate) async fn wait_for_ticket_factory_release(
    factory: &Arc<HoprTicketFactory<RedbStore>>,
    timeout: Duration,
) -> bool
Expand description

Waits up to timeout for every other holder of factory to be gone.

Returns true once only the caller’s reference is left. drop() alone does not suffice: the REST API and the strategies keep the node – and with it a clone of the factory – alive until their tasks actually stop, which is asynchronous.
